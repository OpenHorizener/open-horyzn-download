# Open Horyzn for Mac

This repository only hosts the installer for **Open Horyzn**, the copilot that looks at your screen and draws the next click right on top of it. There is no source code here.

**Download:** https://www.open-horyzn.com/download

## What you need

A Mac with an Apple chip (M1 or newer) and macOS 13 or later. Intel Macs can't run it.

## Install

Open the downloaded file (.dmg) and drag Open Horyzn into your Applications folder.

## Update

Download the new version, quit Open Horyzn and drag it into Applications again. When your Mac asks, replace the old app. Your chats and your key stay on your Mac.
